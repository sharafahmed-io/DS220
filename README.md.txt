# Java Data Structures Portfolio

This repository showcases Java implementations and applications of core data structures.

## Folders

- **core-data-structures-java**: Stack, Queue, Linked List, BST
- **mini-projects-java**: Real-world applications like Infix to Postfix converter
- **algorithm-practice-java**: Common problems using data structures

Each class contains:
- Java implementation
- `main()` for test/demo
- Time complexity notes in comments
